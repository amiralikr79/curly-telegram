**Right Column: Underwriting Standards**

**Headline:**
```
Conservative Underwriting
```

**Underwriting Principles:**

```
**Cost Assumptions:**  
• Construction costs: Market rate + 5% escalation buffer  
• Soft costs: 18–22% of hard costs  
• Contingency: 5–7% of construction budget  
• Timeline buffer: 3–6 months above base case  

**Revenue Assumptions:**  
• Pricing: Based on 90-day trailing comparables  
• No appreciation assumed during hold period  
• Absorption: Conservative 1–2 units per month  
• Discount for pre-sales if applicable  

**Sensitivity Analysis:**  
Every project is stress-tested for:  
• Construction cost overrun: +10% / +15%  
• Revenue decline: –10% / –15%  
• Timeline delay: +3 months / +6 months  
• Combined scenario: All three factors  

**Hurdle Requirements:**  
Projects must achieve:  
• Minimum 15% IRR in base case  
• Minimum 10% IRR in moderate stress scenario  
• Positive return in severe stress scenario  
```

### Category 2: Construction Risk

**Title:**
```
Construction Risk
```

**Mitigation Strategies:**

```
• Fixed-price GC contracts (where feasible)  
• Trusted trade relationships (priority pricing)  
• Weekly site oversight and progress tracking  
• 5–7% contingency budgeting  
• Builder's risk insurance  
• Payment and performance bonds  
• Material escalation buffers  
```

---

### Category 3: Financing Risk

**Title:**
```
Financing Risk
```

**Mitigation Strategies:**

```
• Committed construction financing before close  
• Multiple lender relationships (diversification)  
• Interest rate hedging on longer projects  
• Maintain 12–18 month operating reserves  
• Structured debt covenants (achievable)  
• Pre-negotiated extension options  
```

---

### Category 4: Execution Risk

**Title:**
```
Execution Risk
```

**Mitigation Strategies:**

```
• Proven development team (direct experience)  
• Standardized processes and checklists  
• Experienced consultant network  
• Pre-zoned sites only (no rezoning risk)  
• Pre-application municipal engagement  
• Realistic timeline assumptions  
• Disciplined project pacing (max 5 per year)  
```
